Utilise tes jetons depuis ton code ou n'importe quel outil compatible OpenAI. Chaque appel débite le même solde que le chat, et la réponse indique combien il a coûté.

Démarrage

URL de base : {{ base_url }}

Pour déléguer le choix du modèle, utilise "model": "auto". L'API choisit alors parmi les modèles cloud actifs selon le score disponible et le coût estimé; les modèles nommés restent inchangés.

curl {{ base_url }}/chat/completions \
  -H "Authorization: Bearer sk-ai2ai-VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"model": "openai/gpt-oss-120b", "messages": [{"role": "user", "content": "Bonjour !"}]}'

Python (SDK OpenAI)

from openai import OpenAI

client = OpenAI(api_key="sk-ai2ai-VOTRE_CLE", base_url="{{ base_url }}")

reponse = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[{"role": "user", "content": "Explique le CSRF en une phrase."}],
)
print(reponse.choices[0].message.content)
print(reponse.usage.credits_charged, "crédits débités")

Streaming

flux = client.chat.completions.create(
    model="openai/gpt-oss-120b",
    messages=[{"role": "user", "content": "Écris un haïku."}],
    stream=True,
)
for morceau in flux:
    if morceau.choices:
        print(morceau.choices[0].delta.content or "", end="")
    else:
        print("\n", morceau.usage)  # dernier morceau : crédits débités et solde restant

Le streaming n'est pas encore disponible pour tous les modèles.

Points d'accès

  • POST /v1/chat/completions : conversation.
  • GET /v1/models : modèles et prix.
  • GET /v1/balance : ton solde de crédits.

Limites

  • max_tokens : {{ max_output_tokens }} au maximum (valeur par défaut : 1024). Le pire coût possible est réservé avant l'appel, puis l'excédent est remboursé.
  • {{ rate_limit }} requêtes par tranche de {{ rate_window }} secondes, par clé.
  • Paramètres acceptés : model, messages (texte), max_tokens, temperature, top_p, stop, stream. Les autres sont ignorés (pas d'images, d'appels d'outils ni de n).

Erreurs

401Clé absente ou invalide.
402Crédits insuffisants pour le pire cas de la requête : baisse max_tokens ou recharge.
404Modèle inconnu.
429Trop de requêtes : attends le délai indiqué dans Retry-After.
502La génération a échoué. Tes crédits sont remboursés automatiquement.
