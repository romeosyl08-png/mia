AI 2 AI API

Une API compatible avec les clients OpenAI, alimentée par les modèles configurés dans l'administration Django.

Endpoints

  • GET /v1/models
  • POST /v1/chat/completions

Exemple

from openai import OpenAI

client = OpenAI(
		base_url="{{ base_url }}",
		api_key="votre-cle-api",
)
response = client.chat.completions.create(
		model="identifiant-du-modele",
		messages=[{"role": "user", "content": "Bonjour"}],
)
print(response.choices[0].message.content)

Configurez un fournisseur, son URL de base, un modèle actif et une clé active dans l'administration.
